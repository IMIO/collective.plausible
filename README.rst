====================
collective.plausible
====================

Plausible integration into Plone 6 classic UI

Versions
--------

- Version 1.0a7 and later are for Plone 6.1 / 6.2 and Python 3.10+
- Versions up to 1.0a6 are for Plone 5.2 / 6.0

Features
--------

- Behavior to set plausible fields on content types
- Viewlet to include plausible tracking code in the page
- Statistics browserview @@plausible-view
- Plausible server healthcheck browserview @@plausible-healthcheck
- Optional link to the browserviews in object menu

Installation
------------

Add ``collective.plausible`` to the dependencies of your project (or to the eggs of your buildout),
restart Plone and install it from the Add-ons control panel.


Development
-----------

You only need `uv <https://docs.astral.sh/uv/>`_. The Makefile follows the one generated by
`cookieplone <https://github.com/plone/cookieplone-templates>`_ for a backend add-on ::

    make install         # .venv (Python 3.12, Plone 6.2.3) and instance configuration
    make create-site     # create a "Plone" site with collective.plausible installed
    make start           # http://localhost:8080/Plone (admin / admin)
    make console         # debug console on the instance
    make remove-data     # remove all content (and the .venv)
    make i18n            # update locales

``make clean && PLONE_VERSION=6.1-latest make install`` builds against another Plone release, and
``DELETE_EXISTING=1 make create-site`` recreates the site.

Tests and code quality are managed by `plone.meta <https://github.com/plone/meta>`_ and
`tox <https://tox.wiki>`_ ::

    make test            # tests on Python 3.12 with Plone 6.2.3
    make lint            # pre-commit hooks (black, isort, flake8, zpretty, codespell...)
    make format          # reformat code
    make test-all        # lint, every supported Python / Plone version, dependency checks

Any tox environment can be run directly, e.g. ``uvx --with tox-uv tox -e py313-plone61``.
Do not edit the files generated by plone.meta: change ``.meta.toml`` and run
``uvx --from plone.meta config-package --branch current .`` instead.
